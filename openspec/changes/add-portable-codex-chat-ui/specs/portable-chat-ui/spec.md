## Purpose

Предоставить единый переносимый интерфейс агента, визуально встроенный в чат Minecraft и одинаково управляемый мышью и клавиатурой.

## ADDED Requirements

### Requirement: Portable UI module
Общий UI SHALL предоставляться отдельным модулем, совместимым с Java 8 и независимым от Minecraft, Forge, LWJGL и конкретного backend. Версионный адаптер SHALL предоставлять рисование, метрики текста, ввод и платформенные операции без дублирования компоновки и поведения интерфейса.

#### Scenario: Platform adapter substitution
- **WHEN** общий UI подключён к тестовой поверхности вместо Minecraft
- **THEN** доступны те же компоновка, навигация, выбор диалога и интерактивные карточки

### Requirement: Minecraft chat presentation
UI SHALL встраиваться вкладкой в родной игровой чат, без перехода на отдельный экран. Компактная панель поверх мира SHALL иметь возможность разворота, родной шрифт, полупрозрачный фон и учитывать ширину, масштаб и прозрачность чата. Статусы MUST различаться текстом или символом, а не только цветом.

#### Scenario: First prompt without a conversation
- **WHEN** пользователь отправляет первый непустой запрос без выбранного диалога
- **THEN** UI подключает backend при необходимости, создаёт диалог и отправляет запрос ровно один раз, без обязательного нажатия New
- **AND** ошибка сохраняет текст для повторной попытки, а правки во время подключения остаются в черновике

#### Scenario: Native chat host
- **WHEN** пользователь переключает вкладки Chat и Codex
- **THEN** остаётся тот же игровой GuiChat; сохраняется обычный черновик, а открытие игрового чата через slash сохраняет командный префикс

#### Scenario: Small window and large GUI scale
- **WHEN** окно сужено или увеличен GUI scale
- **THEN** список диалогов доступен через переключатель, ввод и действия не перекрываются, подробности доступны прокруткой или разворотом

### Requirement: Complete command-free interaction
UI SHALL позволять выполнять все доступные действия мышью и клавиатурой без служебных slash-команд. Enter SHALL отправлять текст, Shift+Enter — добавлять строку; Escape SHALL сначала закрывать верхнее меню, затем панель, без отмены задачи.

#### Scenario: Prompt and approval using keyboard
- **WHEN** пользователь вводит запрос и затем выбирает подтверждение через навигацию фокуса
- **THEN** оба действия выполняются без ввода команды или id, а Enter в поле текста не подтверждает появившийся запрос

### Requirement: Stable reading and input
UI SHALL сохранять черновик, курсор и позицию чтения при переключении диалога, изменении размеров и закрытии панели. Новые события MUST NOT сдвигать читателя к концу, если он прокрутил ленту вверх.

#### Scenario: Background output while reading
- **WHEN** пользователь читает старое сообщение и поступает вывод инструмента
- **THEN** сохраняется место чтения и появляется доступное действие перехода к новым событиям

### Requirement: Responsive rendering and private input
UI SHALL отображать большие каталоги и истории без полной загрузки и перерисовки всех элементов за кадр. Текст агента и промпты MUST NOT отправляться в игровой чат или сервер Minecraft.

#### Scenario: Large history
- **WHEN** каталог содержит 100 диалогов, а выбранная история — 10 000 элементов
- **THEN** видимая область остаётся интерактивной, данные подгружаются по требованию и ввод доступен во время потока

#### Scenario: Switch to ordinary chat
- **WHEN** пользователь переключается между Chat и вкладкой агента
- **THEN** получатели сообщений разделены, а черновик агента не появляется в сетевом сообщении Minecraft
