# Community conduct

Be welcoming, respectful and constructive. Discuss the code and the problem; avoid personal attacks, harassment, discriminatory language, threats and sharing someone else's private information.

Maintainers may edit or remove inappropriate contributions, close unproductive discussions and restrict participation when needed. Apply the same standards to everyone, including maintainers. Use GitHub's reporting tools for abuse or contact the repository owner privately through an available GitHub contact channel; do not publish sensitive reports in issues.

This policy applies to repository issues, pull requests, reviews and discussions.
