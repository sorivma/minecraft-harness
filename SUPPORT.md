# Support

Start with the [README](README.md), [Russian guide](README.ru.md) and [Codex compatibility matrix](docs/codex-coverage.md). Use [Discussions](https://github.com/sorivma/minecraft-harness/discussions) for installation and usage questions, and [Issues](https://github.com/sorivma/minecraft-harness/issues/new/choose) for reproducible bugs or feature requests.

Include Harness, Forge, Java and Codex versions, your operating system and a minimal reproduction. Remove tokens and personal conversation data from logs. Security reports follow [SECURITY.md](SECURITY.md).
