# Minecraft Harness 0.1.1

Fixes `Codex process disconnected` during startup on Windows, including GT New
Horizons in Prism Launcher. Java's native process argument serialization removed
the quotes in the world-local `projects` trust override. Codex rejected that value
before the protocol handshake. Harness now preserves quotes and backslashes at
the native process boundary without using a shell.

Replace the old Harness runtime JAR with
`minecraft-harness-forge-1.7.10-0.1.1.jar` while Minecraft is closed. Agent Tools
and Mira remain compatible at 0.1.0. World data, authentication and user settings
do not need changes.

Validation includes a native child-process regression for Windows argument
preservation and a local Codex 0.164.0 initialization check using the affected
GTNH world workspace. The protocol fixture baseline remains 0.163.0, so 0.164.0
still shows a compatibility warning. Full gameplay and a model response are not
covered by the initialization check.
