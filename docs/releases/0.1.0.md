# Minecraft Harness 0.1.0

The first release brings a Codex workspace into Minecraft Forge 1.7.10: separate chat tabs, streamed Markdown, multiple conversations, approvals, questions, planning widgets and MCP mod discovery.

## Choose your artifact

| Asset | Purpose |
| --- | --- |
| `minecraft-harness-forge-1.7.10-0.1.0.jar` | Install in the Forge client's `mods/` folder |
| `minecraft-harness-forge-1.7.10-0.1.0-dev.jar` | Compile addon integrations; do not install as the runtime mod |
| `agent-api`, `core`, `chat-ui`, `agent-codex` JARs | Portable Java 8 libraries for development; dependencies are not bundled |
| `*-sources.jar` | Corresponding module source code |
| `minecraft-harness-0.1.0.zip` | All release artifacts and documentation |
| `SHA256SUMS` | Integrity checks for every downloadable asset |

Use Java 8 for Minecraft and a native Codex executable. The protocol baseline is Codex 0.163.0; other versions show a compatibility warning. Local saves and LAN hosting are supported; remote multiplayer workspaces are not implemented. Default CI validates compilation, tests, architecture and formatting. It does not launch Minecraft, a live Codex backend or real GPU tests.

See the [installation guide](https://github.com/sorivma/minecraft-harness#quick-start), [security policy](https://github.com/sorivma/minecraft-harness/blob/main/SECURITY.md) and [changelog](https://github.com/sorivma/minecraft-harness/blob/main/CHANGELOG.md).
